# Personal Financial Freedom Planner

An Excel-based financial analysis and scenario-planning tool that transforms financial data into actionable insights through financial modelling, data visualization, scenario analysis, and AI-assisted interpretation.

## Project Overview

The Personal Financial Freedom Planner helps users understand:

- Income and expenses
- Monthly savings behaviour
- Investment contributions
- Net worth
- Long-term portfolio growth
- Financial-freedom requirements
- Different investment-return scenarios

The project combines Microsoft Excel with AI-assisted analysis to turn financial data into a structured decision-support dashboard.

## Key Features

### Financial Tracking
- Income and expense tracking
- Transaction categorization
- Monthly financial analysis
- Savings-rate calculation

### Financial Modelling
- Net worth calculation
- Investment growth projection
- Long-term compounding model
- Financial-freedom target calculation
- 4% withdrawal-rate scenario

### Scenario Analysis

Three return scenarios are modelled:

| Scenario | Annual Return |
|---|---:|
| Conservative | 8% |
| Base | 10% |
| Optimistic | 12% |

### Dashboard

The Excel dashboard displays:

- Monthly income
- Monthly expenses
- Monthly savings
- Savings rate
- Current net worth
- Target financial-freedom age
- Projected portfolio value
- Scenario comparison
- Required portfolio
- Funding gap/surplus
- Financial-freedom status

## AI Integration

AI is used as an analytical support layer.

### Workflow

Financial Data
↓
Excel Model
↓
Calculated Metrics
↓
AI-Assisted Interpretation
↓
Human Verification
↓
Documented Insights

Excel performs the core numerical calculations. AI assists with interpreting patterns, comparing scenarios, explaining model outputs, and identifying assumptions and limitations.
