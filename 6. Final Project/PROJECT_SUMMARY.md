# Personal Financial Freedom Planner

## Problem

Many people have financial data but lack a simple way to understand their spending behaviour, savings, investment growth, and long-term financial trajectory.

## What I Built

I built an Excel-based personal financial planning and analysis tool that converts transaction data and user-defined assumptions into financial metrics, investment projections, scenario analysis, and a visual dashboard.

## How It Works

1. Transaction data is recorded and categorized.
2. Monthly income, expenses, investments, savings, and ratios are calculated.
3. Assets, liabilities, and net worth are tracked.
4. Investment growth is projected using compound-growth calculations.
5. Conservative, Base, and Optimistic return scenarios are compared.
6. A simplified 4% rule assumption is used to estimate the portfolio required for financial freedom.
7. Results are presented through an Excel dashboard.
8. AI-assisted analysis is used to interpret the calculated results and generate structured insights.

## Limitations

This is a prototype financial planning model and should not be treated as financial advice.

The current model is based on one month of sample transaction data and simplified assumptions. Investment returns, contributions, inflation, taxes, fees, and future expenses may vary significantly in real-world conditions.

The 4% rule is used only as a simplified planning assumption and does not guarantee sustainable retirement income.
