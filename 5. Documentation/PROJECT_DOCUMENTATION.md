# PERSONAL FINANCIAL FREEDOM PLANNER

## 1. PROJECT OVERVIEW

The Personal Financial Freedom Planner is an Excel-based financial analysis and scenario-planning tool designed to help users understand their income, expenses, savings, investments, net worth, and long-term portfolio growth.

The project combines financial modelling, data analysis, visualization, scenario analysis, and AI-assisted interpretation.

---

## 2. PROBLEM STATEMENT

People often have financial data but lack a simple way to understand their spending behaviour, savings, investment growth, and long-term financial trajectory.

This project addresses that problem by converting financial inputs and transactions into structured analysis and visual insights.

---

## 3. PROJECT OBJECTIVES

The project aims to:

- Track income and expenses.
- Analyse monthly savings behaviour.
- Track net worth.
- Project long-term investment growth.
- Compare different return scenarios.
- Calculate a financial-freedom portfolio target using the 4% rule assumption.
- Present key financial metrics through an interactive dashboard.
- Use AI to assist with interpretation of model outputs.

## 6. FINANCIAL MODEL

The model uses Excel formulas to transform raw financial inputs into analytical outputs.

Key calculations include:

### Savings

Savings = Income − Expenses

### Savings Rate

Savings Rate = Savings ÷ Income

### Net Worth

Net Worth = Total Assets − Total Liabilities

### Financial-Freedom Portfolio

Required Portfolio = Target Annual Expenses ÷ Withdrawal Rate

### Portfolio Projection

The investment projection incorporates:

- Initial investments
- Regular investment contributions
- Assumed annual return
- Investment period

## 11. LIMITATIONS

The current prototype has several limitations:

- The transaction dataset currently covers one month.
- Investment returns are simplified assumptions.
- Actual market volatility is not modelled.
- Taxes and investment fees are not included.
- Future expenses may differ from current assumptions.
- Investment contributions are assumed to remain constant.
- Income growth is not dynamically linked to investment contributions.
- Inflation is currently an input but is not fully integrated into the portfolio projection.
- The 4% rule is a simplified planning assumption and is not a guarantee.

---

## 12. RESPONSIBLE ANALYSIS

This project is designed for educational and analytical purposes.

The model does not provide personalised financial, investment, tax, or legal advice.

All projections are assumption-dependent and should be interpreted as scenarios rather than guaranteed outcomes.

Personal financial data should be protected when using AI tools or sharing project files publicly.
